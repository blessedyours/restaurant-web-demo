# Luma Cocina — Restaurant Web Demo

Demo moderna y responsive para un restaurante ficticio, creada como pieza de portafolio para servicios de desarrollo web.

## Incluye

- Hero comercial de alto impacto
- Menú filtrable por categorías
- Platillos con fotografía, descripción y precio
- Sección de historia del restaurante
- Galería visual
- Reservación por WhatsApp
- Información de contacto y horarios
- Diseño responsive para móvil, tablet y escritorio

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Personalización

Puede adaptarse a un restaurante real cambiando nombre, colores, menú, precios, fotografías, horarios, redes, dirección y número de WhatsApp.

> Proyecto de demostración. Los datos del negocio son ficticios.
